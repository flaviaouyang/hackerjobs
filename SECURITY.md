# Security

Please report vulnerabilities privately through
[GitHub's security advisories](https://github.com/flaviaouyang/hackerjobs/security/advisories/new),
not in a public issue. You'll get a reply within a week.

The site is static: it has no server, accounts or user data. Post HTML from Hacker News is
sanitized before it is published, the pages carry a Content Security Policy, and email addresses
are published only in scrambled form.
